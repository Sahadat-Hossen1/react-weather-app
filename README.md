# 🌦️ React Weather App
## 🌐 Live Demo

🔗 https://react-weather-app-liart-kappa.vercel.app/

A simple and modern weather application built using **React.js**.  
This app allows users to search for any city and view real-time weather information.

---

## 🚀 Features

- 🔍 Search weather by city name  
- 🌡️ Real-time temperature display  
- 🌤️ Weather condition (Cloudy, Sunny, Rainy, etc.)  
- 📅 Current date & time display  
- 📱 Responsive UI (works on mobile & desktop)

---

## 🛠️ Tech Stack

- React.js  
- JavaScript (ES6+)  
- CSS / Tailwind (if used)  
- Weather API (like OpenWeatherMap)
